# CONTEXT — Portfolio Immersive

**Репо:** https://github.com/Vovahudia/portfolio-immersive  
**Live:** https://vovahudia.github.io/portfolio-immersive  
**Стек:** HTML5 / CSS3 / Vanilla JS + GSAP 3.12.5 + ScrollTrigger + Lenis 1.0.42 + SplitType  
**Шрифты:** Anton, Inter, Permanent Marker  
**Стиль:** Neo-Brutalist Immersive, тёмная тема

---

## Файлы
- `index.html` — вся разметка
- `style.css` — все стили
- `script.js` — вся логика
- `wireframe.html` — только начальная структура ux

---

## Что сделано
- Loader (0% → 100%)
- Custom cursor + cursor text при hover
- Noise canvas overlay
- Навигация фиксированная, magnetic эффект
- Hero — "Immersive Digital PORTFOLIO." с sliced/defaced эффектами
- About — манифест + skill tags
- Works grid — 4 карточки с реальными изображениями и описаниями проектов
- Footer — copy email кнопка, соцсети (ссылки и email настроены)
- Деплой на GitHub Pages
